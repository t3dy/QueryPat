EXTRACTION METHODOLOGY
================================================================================

Selection Criteria:
- Extracted letters discussing major works (Ubik, VALIS, Flow My Tears, Scanner Darkly, etc.)
- Letters showing PKD's philosophical thinking (theology, consciousness, reality, authenticity)
- Letters documenting biographical events (marriage, suicide attempt, rehab, births)
- Letters addressing personal struggles (addiction, financial, health, relationships)
- Letters showing intellectual development over 1972-1973 period

Significance Scoring (Applied to all 303 letters):
- Works mentioned: 3 points per work
- Intellectual content: 3 points per theme
- Personal struggles: 2 points per struggle
- Biographical events: 2 points per event
- Thematic richness: 1 point per major theme
- Temporal boost: +1 for 1973 letters

Selection: Top 75 letters by significance score selected for extraction

Data Extraction Process:
1. Parsed markdown source file to identify 303+ individual letters
2. Extracted recipient, date, and letter body for each
3. Performed content analysis to identify themes, works, struggles, events
4. Generated thematic tags and categorizations
5. Created standardized JSON schema for all entries
6. Organized chronologically and by significance

Quality Assurance:
- All letters verified to contain substantive content (>100 characters)
- Recipient and date information validated
- Work and theme identification cross-checked
- Summary text preserved with minimal editing
- Encoding: UTF-8 throughout

3. Note changes in how PKD discusses same work over time

For Philosophy/Theology:

2. Filter for letters with multiple intellectual themes for deeper discussions
3. Note progression from personal crisis to philosophical grounding

Query Examples (using JSON):
